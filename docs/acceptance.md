# 0.2 验收清单

本地入口：[http://localhost:4173](http://localhost:4173)。若服务停止，在 `D:\TimeScape` 执行 `npm ci`（首次）和 `npm run dev`。白色背景、现有图标、主题色及反馈交互保留，图标可下一轮替换。

## 建议先试这些操作

1. 新建日程，输入「下午三点十分到四点四十上课」，点识别：名称为上课，开始 `15:10`，结束 `16:40`，直接保存。
2. 输入「今天晚上十一点到明天凌晨一点值班」并保存：今天显示 `23:00–24:00`，明天显示 `00:00–01:00`。刷新仍保留。
3. 新建「旅行」，开启全天，开始日期选 11 月 9 日、结束选 11 月 11 日：三个日期均可见，11 月 12 日不显示。可根据实际日期替换这一组日期。
4. 新建两条同一时间的安排：每日列表均可见；地图中分行排列，不互相盖住。
5. 在「背单词」待办中选择关联「四级考试」：地图中位于考试下方并连线；日期可以早于考试。每天的待办仍有完成框。
6. 地图拖动上下左右、滚轮缩放、点击加减按钮和滑杆；手机双指捏合。点击「全局」看到所有安排，点击主题聚焦；远景点击事项放大后再点可编辑。
7. 在地图日期控件选择其他月份；点日期刻度跳到每日视图。纯平移不会改变下次新建的默认日期。
8. 新建「仅知晓」的校运会并设置跨天：每日可见，没有完成勾选框，地图中用信息图标与虚线边框区分。
9. 勾选待办后撤销；删除有关联待办的日程后撤销：日程与关联均恢复。
10. 更多选项中导出 JSON，在另一地址导入；重复导入保留现有编号，不产生重复；导入可撤销。

## 已执行的验证

- Node 测试覆盖中文数字/阿拉伯数字、相对日期、跨夜、跨年、全天包含末日、午夜排除次日、无效日期与时间、旧记录升级、损坏数据保护、地图重叠和关联关系、API 输入校验。
- Chromium 浏览器验证创建、编辑、跨天切换、刷新持久化、完成与撤销、删除与关联恢复、导入导出。
- 浏览器实际鼠标拖动、键盘缩放、地图日期跳转；通过 Chromium 触摸事件验证双指缩放。
- 跨年全局视图检查：远隔两年的事项均进入视口，纵向主题标签不挤压重叠，远景点选可放大后编辑。
- 320、390、768、1440 像素宽度无横向溢出；手机缩放控件在底部导航上方；浅色与暗色均检查。
- HTTP 验证 `/api/health`、`POST /api/parse` 及错误方法返回；生产构建由 `npm run build` 验证，并启动本地 production preview 检查编译后的页面及接口。

自动化命令：`npm run check`，当前 25 项测试全部通过。截图保存在 `preview/map-v2-*.png`。浏览器验证使用独立测试上下文，没有清空或写入用户正在使用的浏览器存储。
