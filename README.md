# TimeScape

TimeScape 是一个优先为手机设计的个人日程原型。界面采用 Material You 风格的扁平化设计，浅色模式使用纯白背景，以低饱和绿作为强调色，搭配蓝、薄荷绿、杏色和淡紫色区分主题。浅色和暗色模式默认跟随系统，也可以在顶部手动切换。

手机使用底部导航、胶囊日期选择器和底部编辑面板；宽屏使用侧边导航，并排显示行程与待办。按钮提供按压与水波纹反馈，切换日期、打开表单和勾选待办时有轻量过渡。启用系统的减少动态效果后，动画会关闭。

使用 Node.js 24。在项目目录首次运行 `npm ci`，然后运行 `npm run dev`，打开 [本地预览](http://localhost:4173)。Windows PowerShell 如果拦截 `npm` 脚本，可运行 `npm.cmd run dev`。

真机预览运行 `npm run dev:lan`，在同一 Wi-Fi 的手机上打开终端显示的局域网地址。原来的 `node server.mjs` / `node server.mjs --lan` 入口也保留，内部已改用 Vite。

`npm run check` 执行领域测试及生产构建。`npm run build` 生成 `dist/`；停止开发服务后运行 `npm run preview` 可在相同端口检查生产包。

- 点右下角「＋」选择日程、待办或仅知晓。可以手动填写，也可以输入「下午三点十分到四点四十上课」或「明天背单词」，点「识别」填入表单，确认后保存。
- 点顶部日期条切换本周的日期，或点标题右侧的日期选择其他周。点卡片编辑安排，可为待办选择一项关联日程。
- 开始日期和结束日期可以不同。跨夜如「今天晚上十一点到明天凌晨一点值班」可直接识别；全天如「明天到后天校运会」也支持。全天的结束日期包含在安排中；定时安排在结束时刻截止，凌晨 00:00 结束不会占用下一天。
- 日期未写明时，使用编辑器当前选择的日期；「今天／明天／后天」始终以设备上的实际今天为准。识别使用中文规则，不需要外部模型或 API 密钥，结果可在保存前调整。
- 地图横向是时间，纵向按主题、日程与关联待办展开；同时间的安排分行摆放，关联待办在父日程下方，以线连接。拖动平移，滚轮或双指缩放；「全局」容纳所有安排，点主题聚焦，点日期进入当天。远景中点击事项先放大，再点击编辑。
- 地图也支持缩放按钮、滑杆、日期定位，以及键盘方向键、加减键、`0` / `Home`。卡片保证近景可读，底部细条表示持续时间，卡片宽度不等于短时安排的精确时长。
- 完成待办或删除安排后，可在提示条中点「撤销」。删除日程的撤销也会恢复原有的待办关联。
- 初次打开有示例日程。在右上角的「更多选项」中管理示例；「清除示例日程」只会清除示例和指向它们的关联。

安排和主题偏好仍保存在当前浏览器的本地存储中，原 `timescape.v1` 记录会兼容读取。不同设备、域名、端口的记录各自独立；换到线上地址前，从「更多选项 → 导出备份」下载 JSON，再在新地址导入。导入合并新编号，已有编号保留当前记录，导入也能撤销。读取损坏数据时会显示错误并阻止覆盖。

Vercel 工程配置与 Node Functions 已就绪：`GET /api/health` 和 `POST /api/parse`。本地开发及预览使用相同处理函数。当前没有登录、云数据库或多设备同步，也尚未创建线上部署；Vercel 连接需要重新授权。
